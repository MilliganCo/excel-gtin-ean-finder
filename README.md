# Excel Gtin Ean Finder

## Описание

Desktop-утилита на Python для анализа Excel-файлов со штрихкодами и номенклатурой. Скрипт ищет позиции, у которых найден только один уникальный штрихкод, и сохраняет результат в новый Excel-файл с отдельным проблемным листом.

Проект рассчитан на локальную офисную обработку таблиц без внешних сервисов и API. Основной сценарий использования: быстро проверить товарные данные и выделить позиции, требующие внимания.

## Возможности

- выбор Excel-файла через графический диалог;
- автоматический поиск нужных колонок по распространённым названиям;
- безопасная обработка штрихкодов как строк;
- подсчёт числа уникальных штрихкодов для каждой номенклатуры;
- экспорт результата в новый Excel с двумя листами.

## Стек

- Python
- Tkinter
- pandas
- openpyxl

## Как использовать

1. Запустите `analyze_barcodes.py.py`.
2. Выберите Excel-файл с данными.
3. После завершения откройте новый файл с суффиксом `_analyzed`.
